# Working rules

Fictional notes for the demo user Alex Rivera.

## Mornings
- I always protect two long morning blocks for deep work; calls go after lunch.
- If a decision is reversible, I take it in under five minutes and write down the review date.

## Clients
- Never add a feature to the side project the week a client deadline lands.
- My rule for scope: one page first, then iterate weekly with the client in the room.

## Reading
Clarity over cleverness. If it needs a tooltip, it is not finished.
